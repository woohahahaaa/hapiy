# Hapiy 使用说明

```
Hapiy API 中转平台
│
├── 页面：转发拓扑（可视化流量链路）
│   ├── 模型中心
│   ├── 渠道
│   ├── 心跳回复
│   ├── 并发控制
│   ├── 请求改写
│   ├── 故障转移
│   └── 调试
│
├── 监控
│   ├── 页面：活动监视（按 Session 分组）
│   └── 页面：使用日志（请求历史记录）
│
├── 页面：渠道管理（上游厂商配置）
│
├── 页面：令牌管理（API Key 与额度）
│
├── 页面：价格配置（模型定价）
│
├── 策略配置
│   ├── 页面：请求改写（修改请求体字段）
│   ├── 页面：心跳回复（超时自动回复）
│   ├── 页面：并发控制（限制并发数）
│   └── 页面：故障转移（主备切换）
│
├── 页面：系统设置（安全、磁盘、性能）
│
└── 页面：个人资料（账户信息）
```

---

## 转发拓扑

```
转发拓扑
│
├── 模型中心 — 系统节点，自动取所有渠道的模型并集
│   └── 每个模型连到支持它的渠道
│
├── 渠道 — 一个渠道对应一个节点
│   └── 显示：Base URL 数量、Key 数量、模型数量
│   └── 内嵌启用/禁用开关
│
├── 处理节点（用户自由添加、自由连线）
│   ├── 心跳回复 — 引用策略配置中的心跳回复规则
│   ├── 并发控制 — 引用策略配置中的并发控制规则
│   ├── 请求改写 — 引用策略配置中的请求改写规则
│   ├── 故障转移 — 引用策略配置中的故障转移规则
│   └── 调试 — 选择记录字段 + 存储路径
│
├── 路由规则：每个渠道只走一条路径，不分支
├── 自动布局：魔法棒按钮触发 dagre 分层排列
└── 编辑 JSON：右上角按钮批量修改配置
```

## 活动监视

```
活动监视
│
├── 表格上方有"设置"按钮，可选择分组方式
│   ├── 按用户
│   ├── 按 IP
│   ├── 按 Token
│   └── 按模型
│
├── 按所选字段分组展示 Session
│   └── 每个 Session 卡片
│       ├── 标题：分组字段的值
│       ├── 摘要：请求数 + 总 Token 数
│       └── 表格：状态(彩色圆点) / IP / Token / 模型 / 耗时 / Token 数
│
└── 请求状态
    ├── 连通中（黄色圆点）
    ├── 发数据中（蓝色圆点）
    ├── 收数据中（绿色圆点）
    ├── 排队中（紫色圆点）
    └── 已断开（灰色圆点）
```

## 使用日志

```
使用日志（参考 NewAPI Log 表结构）
│
└── 表格列
    ├── 时间（created_at）
    ├── 用户（username）
    ├── 令牌（token_name）
    ├── 渠道（channel_name）
    ├── 模型（model_name）
    ├── Tokens（prompt / completion，合并列）
    ├── 流式（is_stream — SSE / -）
    ├── 消耗（quota，¥）
    ├── 耗时（use_time）
    └── 状态（成功/失败）
```

## 渠道管理

```
渠道管理
│
├── 表格列
│   ├── 名称
│   ├── Base URLs 数量
│   ├── Keys 数量
│   ├── Endpoints 数量
│   ├── 模型（含折扣标注）
│   ├── 启用/禁用开关
│   └── 编辑 / 删除
│
├── 表单字段
│   ├── 启用开关
│   ├── 名称
│   ├── Base URL（多行，可增删）
│   ├── Key（多行，可增删）
│   ├── Endpoint（多行，可增删）
│   └── 模型（多行）
│       ├── 模型 ID
│       ├── 绑定 Endpoint（多选，默认"不限"=全部端点可用）
│       └── 折扣（如 0.85 = 八五折，留空=无折扣）
│
└── 编辑 JSON：右上角按钮批量修改
```

## 令牌管理

```
令牌管理

├── 表格列
│   ├── 名称
│   ├── Token
│   ├── 额度（¥，留空=不限制）
│   ├── 启用/禁用开关

│   └── 额度（¥，留空=不限制）
│
└── 编辑 JSON：右上角按钮批量修改
```

## 策略配置

```
策略配置
│
├── 请求改写（表格列表 + DSL 编辑器）
│   ├── 表格列：名称 / 脚本(首行预览) / 开关 / 操作
│   └── 编辑弹窗：名称 + 大文本编辑器 + 语法参考侧栏
│       ├── SET field = value — 设置字段
│       ├── DELETE field — 删除字段
│       ├── IF cond THEN { ... } — 条件执行
│       ├── IF cond ~ "wild*" — 通配符匹配
│       ├── header.X-Name — Header 操作
│       ├── nested.key.sub — 嵌套字段
│       └── {{request_id}} / {{timestamp}} — 内置变量
│
├── 心跳回复
│   ├── 表格列：名称 / 匹配条件 / 回复内容 / 超时 / 开关 / 操作
│   └── 表单：名称 / 匹配条件(*,stream_timeout) / 回复内容 / 超时(秒) / 开关
│
├── 并发控制
│   ├── 表格列：名称 / 作用域 / 最大并发 / 排队 / 开关 / 操作
│   └── 表单：名称 / 作用域(全局,每用户,每令牌) / 最大并发 / 排队开关 / 开关
│
└── 故障转移
    ├── 表格列：名称 / 主渠道 / 备选 / 触发条件 / 开关 / 操作
    └── 表单：名称 / 主渠道 / 备选 / 触发条件(超时,错误,限流) / 开关
```
