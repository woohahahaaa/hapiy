# 项目开发状态

## 项目定位

本项目基于 New API 进行二次开发，当前复用其 AI API 网关与代理能力，围绕新的前端交互和管理界面进行原型设计。

## 当前阶段

项目目前处于调试阶段，目标是完成纯前端框架与交互原型。页面中的数据、流程和配置项可能仍为模拟实现，不代表已经接入完整后端业务。

## 模块状态

- 部分原有模块已删除，或在当前前端中不再提供入口。
- 部分确认暂不使用的模块仅做临时禁用，尚未直接删除，以降低误删依赖和引入回归问题的风险。
- 临时禁用的模块将在代理能力、路由依赖和关联业务经过验证后，再决定是否彻底移除。

## 开发原则

- 保留 New API 现有的 API 代理能力作为项目基础。
- 优先验证前端信息架构、页面布局和交互流程。
- 在原型稳定前，避免将临时 UI 或模拟数据视为正式业务实现。
- 每次删除或启用模块前，先确认其路由、前端依赖和后端调用关系。
